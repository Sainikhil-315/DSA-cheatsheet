01

Arrays

Prefix Sum

  • pre[i] = pre[i-1] + arr[i]
  • Range sum [l,r] = pre[r] - pre[l-1]
  • Subarray sum = k → use prefix + hashmap
Brute: O(n²) nested loop for every pair
Optimal: Build prefix array O(n), query O(1)

Kadane's Algorithm

  • Max subarray sum
  • curSum = max(arr[i], curSum + arr[i])
  • maxSum = max(maxSum, curSum)
  • Reset when curSum < 0
Brute: O(n²) all subarrays, track max

Merge Intervals

  • Sort by start time first
  • If cur.start ≤ last.end → merge (extend end)
  • Else push cur as new interval
Brute: Sort + compare each pair O(n²)

Next Greater Element

  • Use monotonic stack (decreasing)
  • Pop when cur > stack top → that's NGE
  • Circular: iterate 2n, mod n for index
Brute: O(n²) for each element scan right

Rotate Array

  • Reverse full → reverse [0,k-1] → reverse [k,n-1]
  • k = k % n (handle k > n)
Brute: Extra array, place arr[i] at (i+k)%n

Majority Element

  • Boyer-Moore Voting: candidate + count
  • count=0 → new candidate
  • Same → count++, diff → count--
  • Verify candidate in 2nd pass (if needed)
Brute: HashMap count, find > n/2

3Sum / 4Sum

  • Sort array first
  • Fix one (or two) → two pointer on rest
  • Skip duplicates after finding a result
Brute: O(n³) three nested loops, use set

Trapping Rain Water

  • water[i] = min(maxL, maxR) - height[i]
  • Two-pointer: move smaller side inward
  • Precompute leftMax[], rightMax[]
Brute: For each i, scan left/right for max O(n²)
02

Strings

Anagram Check

  • Sort both strings: equal → anagram
  • Or freq array of 26 chars
  • Group anagrams: sort each word as key
Brute: Sort s1, sort s2, compare O(n log n)

Palindrome

  • Two pointers: l=0, r=n-1, compare inward
  • Longest palindrome substr: expand from center
  • Even centers: (i, i+1); Odd: (i, i)
Brute: O(n²) check all substrings

String Matching (KMP idea)

  • Basic: use find() or nested loop
  • Build LPS array for pattern
  • LPS[i] = longest proper prefix = suffix
Brute: O(n*m) slide pattern, check char by char

Longest Common Subsequence

  • dp[i][j]: LCS of s1[0..i] s2[0..j]
  • If match: dp[i][j] = 1 + dp[i-1][j-1]
  • Else: max(dp[i-1][j], dp[i][j-1])
Brute: Recursion all subsequences O(2^n)

Roman / Number Conversion

  • Map symbols → values
  • If s[i] < s[i+1] → subtract, else add
  • Build greedily largest → smallest
Brute: Iterate with map, handle subtractive pairs

Valid Parentheses

  • Stack: push open, pop on close
  • Check matching pair on pop
  • End: stack must be empty
Brute: Count open/close (only works for one type)
03

Hashing

Frequency Map Pattern

  • unordered_map<int,int> freq
  • Top K frequent: min-heap of size K
  • First unique char: freq then scan
Brute: Nested loops to count occurrences

Subarray Sum = K

  • prefix sum + hashmap
  • mp[prefix - k] gives count of valid starts
  • Init: mp[0] = 1
Brute: O(n²) all subarrays, sum each

Two Sum / Four Sum

  • Map: store val → index
  • For each num: check if (target - num) exists
  • Insert after check (avoid same index)
Brute: O(n²) check all pairs

Longest Consecutive Sequence

  • Put all nums in unordered_set
  • Start streak only if (n-1) not in set
  • Extend: count while (n+1) exists
Brute: Sort, scan O(n log n)
04

Two Pointers

When to use

  • Sorted array + find pair/triplet
  • Remove duplicates in-place
  • Container with most water
  • Partitioning (Dutch flag)

Template

  • l = 0, r = n-1
  • while l < r: check condition
  • If too small → l++
  • If too large → r--
  • If match → record, move both
Brute: Sort + O(n²) nested check

Dutch National Flag

  • Sort 0s, 1s, 2s in one pass
  • low=0, mid=0, high=n-1
  • 0 → swap(low,mid), low++, mid++
  • 1 → mid++
  • 2 → swap(mid,high), high--

Container With Most Water

  • l=0, r=n-1
  • area = min(h[l], h[r]) * (r-l)
  • Move pointer with smaller height
Brute: O(n²) all pairs
05

Sliding Window

Fixed Window

  • Max/min sum of k elements
  • Add right, subtract left element
  • Maintain window size = k
Brute: O(n*k) nested loop

Variable Window

  • l=0, r=0, expand r, shrink l
  • Shrink when condition violated
  • Track max window size
  • Use hashmap for char freq
Brute: O(n²) all substrings

Longest Substring No Repeat

  • unordered_map for last seen index
  • l = max(l, mp[c] + 1) on repeat
  • ans = max(ans, r - l + 1)

Min Window Substring

  • need map (pattern freq), have map (window freq)
  • formed = chars with required freq
  • Shrink when formed == required
  • Track min window

Binary Search

Classic Template

  • lo=0, hi=n-1, mid=(lo+hi)/2
  • if arr[mid]==target → found
  • if arr[mid] < target → lo=mid+1
  • else → hi=mid-1
  • Loop: while lo <= hi

Lower / Upper Bound

  • lower_bound: first pos ≥ target
  • upper_bound: first pos > target
  • Count occurrences = ub - lb
  • Use < for lb, <= for ub condition

On Answer (BS on result space)

  • When: min/max of something feasible
  • Define: check(mid) → bool
  • lo = min possible, hi = max possible
  • Find last/first valid mid
  • Examples: Koko eating bananas, allocate books
Brute: Linear scan all possible answers

Rotated Sorted Array

  • Find which half is sorted
  • if arr[lo] <= arr[mid]: left half sorted
  • Check if target in sorted half
  • Move lo/hi accordingly
Brute: Linear scan O(n)

Peak Element / Mountain

  • if arr[mid] < arr[mid+1]: peak is right
  • else: peak is at mid or left
  • Mountain array: binary search on slope

2D Matrix Search

  • Treat as 1D: mid → (mid/cols, mid%cols)
  • Or: start top-right, go left/down
07

Recursion / Backtracking

Backtracking Template

  • Base case → add to result, return
  • For each choice: make choice
  • Recurse with updated state
  • Undo choice (backtrack)
Key: Think "decision tree" — each node is a state

Subsets

  • At each index: include or exclude
  • 2^n subsets total
  • Duplicates: sort + skip same element at same level
  • if i>start && arr[i]==arr[i-1]: continue

Permutations

  • Swap approach: swap(arr[i], arr[start])
  • Recurse for start+1
  • Swap back to restore
  • Or: used[] bool array + build path

Combination Sum

  • Can reuse: recurse same index
  • Can't reuse: recurse i+1
  • Prune: if sum > target, return
  • Sort first for better pruning

N-Queens / Sudoku

  • Place, validate constraints, recurse
  • If invalid, remove and try next
  • N-Queens: check row, col, diagonals
  • Sudoku: check row, col, 3x3 box

Word Search

  • DFS from each cell
  • Mark visited: board[r][c] = '#'
  • Restore: board[r][c] = original
  • 4 directions: dr[]={0,0,1,-1}
08

Sorting

Merge Sort

  • Divide at mid, sort halves, merge
  • Merge: compare & pick smaller O(n)
  • Use for: count inversions, sort linked list
  • Stable, O(n log n), O(n) space

Quick Sort

  • Pick pivot (last/random), partition
  • Elements < pivot | pivot | elements > pivot
  • Recurse on both sides
  • Avg O(n log n), Worst O(n²)

Custom Sort Tricks

  • Sort by freq: sort with comparator
  • Sort intervals by start: sort(v.begin(), v.end())
  • sort(arr, arr+n, greater<int>()) for desc
  • Partial sort: nth_element O(n)

Counting / Radix Sort

  • When range small: count array of size max+1
  • Count freq → prefix → place elements
  • O(n+k) time, O(k) space
  • Useful for: sort 0/1/2, characters
09

Linked List

Floyd's Cycle Detection

  • slow=fast=head
  • slow=slow→next, fast=fast→next→next
  • Meet → cycle exists
  • Find start: reset one to head, move both by 1
Brute: HashSet of visited nodes

Reverse Linked List

  • prev=null, cur=head
  • next=cur→next, cur→next=prev
  • prev=cur, cur=next
  • Return prev

Find Middle

  • slow/fast pointers
  • fast moves 2x speed
  • When fast reaches end, slow = mid
  • Odd: exact mid. Even: upper mid

Merge K Sorted Lists

  • Min-heap (priority_queue)
  • Push heads of all lists
  • Pop min, push its next
  • O(n log k) where k = num lists
Brute: Collect all, sort, rebuild O(n log n)

LRU Cache

  • HashMap + Doubly Linked List
  • Map: key → node
  • DLL: maintains access order
  • Get: move to front; Put: evict tail if full

Intersection of Lists

  • Two pointer: when one ends, redirect to other's head
  • They meet at intersection (or null)
  • Lengths equalize via redirection
Brute: HashSet of nodes from list A, check in B
10

Stack / Queue / Monotonic

Monotonic Stack

  • Increasing: pop if cur < top (find prev greater)
  • Decreasing: pop if cur > top (find next greater)
  • Used in: histogram, NGE, stock span
  • Stores indices usually, not values

Largest Rectangle in Histogram

  • Monotonic increasing stack
  • For each bar: pop while cur < top
  • Width = cur_idx - stack.top() - 1
  • Area = height[popped] * width
Brute: O(n²) expand left/right for each bar

Sliding Window Maximum

  • Monotonic deque (decreasing)
  • Remove indices outside window from front
  • Remove smaller elements from back
  • Front of deque = max of window
Brute: O(n*k) scan each window

Min Stack

  • Two stacks: main + minTracker
  • Push to minTracker if ≤ current min
  • Pop from minTracker if top = popped value
  • Or: store (val, currentMin) pairs
11

Trees

Traversals

  • Inorder (L-Root-R): BST gives sorted
  • Preorder (Root-L-R): copy tree, serialize
  • Postorder (L-R-Root): delete tree
  • Level order: BFS with queue
  • Morris traversal: O(1) space inorder

Height / Diameter

  • Height: 1 + max(left, right)
  • Diameter: left_h + right_h at each node
  • Track global max via reference/pointer
  • Balanced: |left_h - right_h| ≤ 1

LCA (Lowest Common Ancestor)

  • If root==null or root==p or root==q: return root
  • Recurse left and right
  • Both non-null → root is LCA
  • Else return non-null one

BST Operations

  • Search: go left if <, right if >
  • Insert: reach null, insert there
  • Delete: 3 cases (leaf, one child, two children)
  • Two children: replace with inorder successor
  • Validate BST: inorder must be strictly increasing

Path Sum Problems

  • Root-to-leaf sum: pass remaining target
  • Any path sum: at each node, max(0, left) + max(0, right) + val
  • Path with max sum: use global variable

Serialize / Deserialize

  • Preorder + null markers ("null,")
  • Use queue for deserialization
  • Split by delimiter, build recursively
12

Graphs

BFS

  • Queue + visited array
  • Shortest path in unweighted graph
  • Level-by-level exploration
  • Multi-source BFS: push all sources initially
Use when: shortest path, level order, nearest X

DFS

  • Recursive or stack + visited
  • Connected components: DFS from each unvisited
  • Detect cycle: visited + recursion stack
  • Topological sort: post-order DFS
Use when: all paths, cycle detect, topo sort

Dijkstra's

  • Min-heap (dist, node)
  • dist[] = INF, dist[src] = 0
  • Relax edges: if dist[u]+w < dist[v], update
  • Only works with non-negative weights
Brute: Bellman-Ford O(VE) for negative weights

Topological Sort

  • DFS: add to stack after visiting all neighbors
  • Kahn's (BFS): in-degree array
  • Add zero in-degree to queue, decrement neighbors
  • If output size < V: cycle exists

Union-Find (DSU)

  • find(x): path compression
  • union(x,y): rank-based union
  • Use: detect cycle, count components
  • MST (Kruskal): sort edges, union if no cycle

Grid Problems

  • Treat cells as graph nodes
  • 4-directional: dr={0,0,1,-1}, dc={1,-1,0,0}
  • Islands: DFS/BFS flood-fill, mark visited
  • 0-1 BFS: deque (0-cost front, 1-cost back)
Classic: Number of islands, shortest path in maze
13

Dynamic Programming

1D DP Patterns

  • Fibonacci / Climbing stairs
  • House robber: dp[i] = max(dp[i-2]+arr[i], dp[i-1])
  • Jump Game: check if can reach each index
  • Decode ways: dp[i] = dp[i-1] + dp[i-2] (if valid)
Brute: Recursion with memoization → then tabulate

Knapsack (0/1)

  • dp[i][w] = max value using i items, capacity w
  • Include: dp[i-1][w-wt] + val; Exclude: dp[i-1][w]
  • Space opt: 1D array, traverse right to left
  • Subset sum: dp[i][j] = dp[i-1][j] || dp[i-1][j-arr[i]]

LIS (Longest Increasing Subsequence)

  • O(n²): dp[i] = max(dp[j]+1) for j<i, arr[j]<arr[i]
  • O(n log n): patience sorting with binary search
  • tails[] array: lower_bound replacement

2D DP / Grid DP

  • Unique paths: dp[i][j] = dp[i-1][j] + dp[i][j-1]
  • Min path sum: dp[i][j] = grid[i][j] + min(up, left)
  • Edit distance: if match dp[i-1][j-1], else 1+min(3 ops)

Partition / Palindrome DP

  • Palindrome partition: isPalin[i][j] precomputed
  • Min cuts: dp[i] = min cuts for s[0..i]
  • Burst balloons / matrix chain: interval DP
  • dp[i][j] = best way to solve subproblem [i..j]

Stock Problems

  • Buy once: min so far, max profit
  • Infinite tx: add profit when price rises
  • K tx: dp[k][i] states
  • Cooldown: dp[i] = max(dp[i-1], dp[i-2] + profit)
14

Greedy

When Greedy Works

  • Greedy choice property holds
  • Optimal substructure exists
  • Prove by exchange argument
  • Common hint: sort first, then greedy

Interval Scheduling

  • Max non-overlapping: sort by end time
  • Pick earliest ending, skip overlapping
  • Min intervals to cover: sort by start

Jump Game

  • Track maxReach at each step
  • If i > maxReach → can't proceed
  • Jump Game II: count jumps when reaching threshold
  • Update threshold at each jump

Task Scheduling / Candy

  • Candy: two passes (left→right, right→left)
  • Task scheduler: freq count + cooldown math
  • Huffman: min-heap, combine two smallest

⚡ TOMORROW GAME PLAN
1. Read problem fully. Note constraints (n ≤ 10⁵ → O(n log n) or better; n ≤ 10³ → O(n²) ok)
2. Brute force it mentally first. Write pseudocode.
3. Look for pattern: sorted? → BS/2ptr. Substring? → Window. Count? → HashMap. All? → Backtrack. Optimal? → DP/Greedy.
4. Code brute if optimal not obvious. Partial marks > no submission.
5. Edge cases: empty input, n=1, all same elements, INT overflow (use long long).
